# AgentRouter 自动签到（Scripting）

在 iOS / iPadOS 的 **Scripting** App 里运行的 AgentRouter 每日自动签到脚本：账号密码登录 → 端到端核验签到日志 → 首页展示账号余额 → 桌面小组件看板 → 支持每天自动跑一次并推送通知。

> 由青龙面板 Python 脚本 `agentrouter_checkin.py` 移植，把环境变量配置改为 App 内的图形界面。

## 功能

- **iOS 桌面小组件**：支持添加 `systemSmall`（小组件）与 `systemMedium`（中组件）到主屏幕，无需打开 App 即可一眼查看总资产、各账号额度与今日打卡状态。
- **多账号与单账号签到**：支持一键签到全部账号，也支持在主页直接为单个账号独立签到。
- **端到端核验**：签到后再读一次个人日志（`/api/log/self`），确认当日确有 `type=4` 或内容含「签到成功」的记录，避免「登录成功但签到没真正触发」的漏签。
- **账户余额与本次新增**：主页直接显示每个账号的余额、已用额度与请求次数，签到后立刻显示本次签到后的余额与本次新增（如 `本次 +$25.00`）。
- **免登录刷新余额**：刷新余额只用签到登录时保存下来的会话请求 `/api/user/self`，**不调用登录接口**，避免请求太频繁被站点限流返回 4xx。
- **自动刷新策略**：每天首次进入主页自动刷新一次；其余时间点按账号行或「刷新余额」手动更新。
- **智能批量导入与去重**：右上角「账号」里可添加/修改/删除账号，批量导入支持智能识别多种常见格式（`#`、`----`、冒号、逗号、制表符、空格），并自动过滤已存在的同邮箱账号。
- **安全与差量清理**：密码保存在系统钥匙串（Keychain），账号删除（包括左滑快捷删除）会自动同步清理孤立的钥匙串密码。
- **签到历史记录**：自动记录最近历史记录，统计成功率与获得的累计收益，支持一键清空。
- **网络轻量重试**：网络请求内置重试机制，大幅增强自动化在早晨后台唤醒执行时的网络稳定性。
- **静默模式**：运行 URL 加 `?auto=1` 时不开界面，直接签到并发通知，便于用「快捷指令」做每日自动化。

## 安装

1. 先安装 [Scripting](https://scripting.fun) App。
2. 在 Scripting 中直接导入源码目录：
   `https://github.com/cloudsonly/scripting/AgentRouter签到`
   也可下载同名 `AgentRouter签到.scripting` 兼容安装包导入。
3. 打开脚本 → 右上角「账号」→ 添加账号（或粘贴批量文本导入）→ 保存。

## 使用

- **签到**：右上角「签到」（全量），主页各账号右侧绿色「签到」（单账号），或主页底部的「立即签到」。
- **看余额**：主页「账户余额」分组；点某个账号行可单独刷新。
- **桌面小组件**：长按 iOS 主屏幕 → 点击左上角 `+` → 找到「脚本 (Scripting)」→ 选择「AgentRouter签到」小组件（小号或中号）。
- **每天自动签到**：快捷指令 → 自动化 → 每天固定时间运行「AgentRouter签到」；
  或运行 URL 后加 `?auto=1` 静默执行。

## 余额是怎么算的

| 项目 | 说明 |
| --- | --- |
| 换算单位 | `GET /api/status` 的 `quota_per_unit`（本站为 `500000`，即 500000 quota = $1） |
| 余额来源 | `GET /api/user/self` 的 `quota` / `used_quota` / `request_count` |
| 鉴权 | 复用签到时保存的会话（Cookie + `New-API-User` + `Authorization: Bearer` 三种方式兼容） |
| 签到奖励 | 每天签到 +$25（即 12,500,000 quota） |

会话失效（长时间没签到、站点改版）时，账号行会提示「需要重新签到登录」，点一次签到即可恢复。

每次发布同时更新源码目录和同名 `.scripting` 兼容安装包。

## 目录结构

```
AgentRouter签到/
├── script.json      # 脚本元信息（名称/图标/版本/入口）
├── index.tsx        # 入口：正常打开界面；?auto=1 静默签到并发通知
├── views.tsx        # 界面：MainView（余额/签到/历史/结果）、AccountsView（账号与设置）、AccountEditor
├── widget.tsx       # 桌面小组件：systemSmall / systemMedium 资产看板
└── agentrouter.ts   # 核心逻辑：登录、签到核验、余额与会话、通知、去重导入、Keychain 差量同步
```
